# Рейтинг влучань — тилові міста

Додаток (PWA) з рейтингом тилових міст України за кількістю влучань за повідомленнями офіційних Telegram-каналів ОВА та міських голів.

Сторінка: https://ugi-analytics.github.io/rating/

Дані оновлюються автоматично скриптом `rating_vluchan_mist.py` на ПК аналітика (публікація `index.html` через GitHub API).
